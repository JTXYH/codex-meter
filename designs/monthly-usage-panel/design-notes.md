# 月度用量设计

本轮仅输出可交互效果图，尚未修改 Swift 应用代码。

## 已确认的范围

- 所有费用数值去掉约等于符号，继续使用「API 等效费用」标签和已有说明。
- 活跃度概览保留昨日、近 7 天，新增本月 Token、本月 API 等效费用，采用两行两列。
- 新增独立的「月度统计」卡片，按月份展示 Token 与 API 等效费用。
- 用户确认支持显隐、近 3 / 6 / 12 个月及卡片排序；默认显示近 6 个月，包含当前月。
- 继续使用现有浅色 / 深色颜色、系统字体、面板宽度、圆角与描边。预览只聚焦用量区域，额度、热力图、余额不重新设计。

## 统计与交互

- 本月按本地日历的自然月统计，截至当前时刻。
- 表头与月份、Token、费用数值统一左对齐。
- 月份按新到旧排列；当月直接显示「本月」，当年其余月份显示「8 月」等短标签，跨年才带年份。本月行轻微突出；无本机记录的月份显示横杠。
- 月度卡片标题右侧可进入配置，设置中的修改即时体现在预览中。
- 隐藏月度卡片后保留其范围和位置；开关不会隐藏活跃度概览里的本月指标。
- 示例数据仅用于检视布局，不代表用户账单。

## 后续开发计划

1. 从已有每日用量缓存聚合自然月统计，复用增量读取，不新增历史全量扫描。
2. 将本月用量与逐月列表接到 UsageStore，保留加载态。
3. 增加月度统计的显隐、月份范围与卡片排序配置，以及各语言文案。
4. 接入视图并移除金额前缀，验证跨年 / 月初 / 缺失记录 / 缓存更新。
5. 验证真实日志性能、界面与打包。

## 月度卡片样式探索

用户对列表视觉不满意，新增三种可选呈现，原列表设计保留以便比较：

- A 月份卡片：每月独立小卡，六个月两列三行，优先推荐。
- B 横向用量条：每月保留双指标，用横条比较 Token 用量。
- C 按月切换：点击月份显示当月 Token 和 API 费用，节省纵向空间。

三种方案沿用显隐、3/6/12 个月和排序配置，当前月简称「本月」，当年其余月份省略年份。样式尚待选择，未开始应用代码开发。

## 最新开发确认

采用 C 按月切换方案。用户要求全界面使用常规字重，不保留粗体或半粗体。月份标签全部省略年份（当前月仍为「本月」），悬停月份或柱条显示完整年月日范围。此要求覆盖此前跨年显示年份的设计。

## 范围浮层调整（设计阶段）

用户反馈原生范围菜单存在多余二级选择。新增「Monthly Range Popover.html」：右上角直接展开紧凑单层浮层，3/6/12 个月一览，当前项浅紫底与勾选标识；选中即切换并关闭，点击外部或 Esc 关闭。继续使用常规字重和无年份月份标签。本次仅改设计预览，尚未改 Swift 菜单。

## 范围浮层已实现

按用户确认的设计改为卡片内单层浮层，三个范围直接可选；当前项浅紫色背景与勾选，文字使用全局常规字重。选中即关闭，点击外部、重复点击触发按钮、滚动、窗口失焦或 Esc 均可关闭。事件监听仅在浮层可见时存在。原生窗口验证点选、Esc、点击外部关闭；70 项回归测试通过。
