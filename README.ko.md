# Codex Meter

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · [日本語](README.ja.md) · 한국어 · [Español](README.es.md)

Codex Meter는 ChatGPT/Codex 계정의 할당량 창과 token 활동을 빠르게 확인할 수 있는 macOS 네이티브 메뉴 막대 유틸리티입니다. 로컬 Codex CLI의 `app-server` JSON-RPC 인터페이스에서 데이터를 읽고 기존 로그인 상태를 재사용하며, 액세스 토큰을 읽거나 저장하지 않습니다.

> Codex Meter는 독립적인 오픈 소스 프로젝트입니다. OpenAI의 공식 제품이 아니며 OpenAI의 지원이나 추천을 의미하지 않습니다.

## 주요 기능

- 메뉴 막대에 Codex 5시간 남은 할당량을 우선 표시하고, 계정이 주간 할당량만 반환하면 자동으로 주간 값으로 전환
- 할당량 카드와 같은 색의 진행 링을 메뉴 막대에 표시하고 남은 비율에 따라 갱신. 크기를 12~22 pt로 조절하고 실시간으로 미리 보기 가능
- API가 반환한 기간에 맞춰 할당량 카드를 조정. 5시간 할당량은 재설정까지의 시간과 시각을, 주간 할당량은 남은 비율과 재설정 날짜를 한 줄로 표시
- 오늘 상세, 어제, 최근 7일, 이번 달, 누적 Token과 API 환산 비용, 연속 사용일, 최장 작업 표시
- 요일에 맞춰 작은 격자로 채운 120일 히트맵을 표시하고 마우스를 올려 일별 사용량 확인
- 로컬 Codex 세션 로그에서 오늘의 Token을 5초마다 증분 갱신하고 입력, 출력, 캐시 입력, 미화 API 환산 비용 표시
- 오늘 상세에 예상 할당량 사용 비율 표시. 사용량 통계에서는 Token, API 환산 비용, 선택한 기간의 할당량 사용량을 나란히 표시
- 오늘 상세에 모델별 입력·출력 Token, API 환산 비용, 사용 비중 표시. 사용량 통계에서도 같은 형식으로 선택한 일·주·월·연도의 모델별 내역 표시
- Codex Credits 잔액을 미화 가치로 환산해 표시
- 메인 패널의 모든 카드를 개별적으로 표시·숨김하고 드래그해 순서를 바꾸며 설정은 자동 저장
- 수동 새로고침, 기본 간격, 1~1,440분 사용자 지정 간격 지원
- 로그인 시 실행 또는 Codex 데스크톱 앱과 함께 시작·종료 지원. 시스템, 라이트, 다크 모드 선택 가능
- 할당량 조회 시 Codex/ChatGPT 데스크톱 앱 내장 CLI를 우선 사용하며 수동으로 지정한 CLI 경로가 있으면 이를 최우선 사용
- 수치, 제목, 레이블·설명의 글자 크기를 콘텐츠 카드별 또는 일괄 조절하고 할당량 카드는 별도로 설정
- 여러 사용자 지정 할당량 배경 세트를 만들고 여유·주의·부족 상태별 카드 이미지와 패널 아이콘을 잘라 남은 할당량에 따라 자동 전환
- Sparkle로 6시간마다 업데이트를 확인하고 앱 내에서 검증·설치·재시작
- 계정 이메일을 기본으로 가리고 직접 클릭할 때만 전체 주소 표시
- 할당량 새로고침 실패 시 마지막 성공 데이터 유지. 첫 조회에 실패해도 로컬 사용량을 표시하고 할당량 다시 시도 제공
- 통계, 설정, 배경 이미지를 로컬 SQLite에 저장하고 설정에서 기간별 사용 기록 정리 가능

### 첫 실행 시 macOS가 앱을 차단하는 경우

현재 빌드는 ad-hoc 서명을 사용하며 Apple 공증을 받지 않았습니다. 첫 실행 시 “Apple에서 앱에 악성 소프트웨어가 있는지 확인할 수 없습니다” 또는 “앱 개발자를 확인할 수 없습니다”라는 경고가 표시되면 먼저 이 저장소의 [GitHub Releases](https://github.com/JTXYH/codex-meter/releases)에서 다운로드한 앱인지 확인한 다음 아래 방법 중 하나를 사용하세요.

**방법 1: Finder에서 열기**

1. Finder에서 응용 프로그램 폴더를 열고 `CodexMeter.app`을 찾습니다.
2. Control 키를 누른 채 앱을 클릭하거나 오른쪽 클릭한 다음 **열기**를 선택합니다.
3. 확인 창에서 **열기**를 한 번 더 클릭합니다. 한 번 허용하면 다음부터는 이중 클릭하여 정상적으로 실행할 수 있습니다.

**방법 2: 시스템 설정에서 허용하기**

1. `CodexMeter.app`을 한 번 이중 클릭한 다음 macOS 경고를 닫습니다.
2. Apple 메뉴 ** → 시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
3. 아래로 스크롤하여 보안 섹션에서 Codex Meter에 대한 메시지를 찾고 **그래도 열기**를 클릭합니다.
4. 요청대로 본인 인증을 완료한 다음 **열기**를 클릭합니다. **그래도 열기** 버튼은 보통 앱 실행을 시도한 후 약 1시간 동안만 표시됩니다.

자세한 내용은 [Apple 지원: Mac에서 앱 안전하게 열기](https://support.apple.com/ko-kr/102445)를 참고하세요. macOS가 앱이 “컴퓨터를 손상시킬 것”이라고 명확히 알리거나 악성 소프트웨어를 감지하면 경고를 우회하지 마세요. 현재 파일을 삭제하고 공식 Release에서 다시 다운로드하세요.

Sparkle이 처음 포함된 버전부터 업데이트 패키지는 Ed25519로 서명되며 앱 내에서 설치됩니다. 기존 버전이 브라우저 다운로드를 사용한다면 전환 버전을 한 번 수동 설치해야 합니다. 이후 업데이트에서는 같은 Gatekeeper 확인을 반복하지 않아도 됩니다.

## 시스템 요구 사항

- macOS 14 Sonoma 이상
- Codex/ChatGPT 데스크톱 앱 내장 또는 별도로 설치한 [Codex CLI](https://github.com/openai/codex) 사용 가능 및 ChatGPT 계정 로그인
- Swift 6 / Xcode 16 이상(소스에서 빌드할 때만 필요)

Codex Meter는 수동으로 지정한 CLI 경로를 최우선으로 사용하고, 이후 Codex/ChatGPT 데스크톱 앱 내장 `codex`, `PATH`, `~/.local/bin/codex`, `~/.npm-global/bin/codex`, 일반적인 Homebrew 경로, 기타 앱 내부 실행 파일을 찾습니다.

## 설치

저장소를 클론하거나 다운로드한 다음 실행하세요.

```bash
cd codex-meter
chmod +x scripts/build-app.sh
./scripts/build-app.sh
```

`dist/CodexMeter.app`에 앱이 생성됩니다. 바로 실행하거나 응용 프로그램 폴더로 옮기세요.

개발 중에는 다음과 같이 실행할 수 있습니다.

```bash
swift run CodexMeter
```

## 사용 가이드

1. Codex CLI 또는 Codex 데스크톱 앱에서 ChatGPT 계정으로 로그인했는지 확인합니다.
2. Codex Meter를 실행하면 메뉴 막대에 색상이 있는 할당량 링과 5시간 남은 할당량이 표시됩니다. 주간 할당량만 있으면 자동으로 주간 값으로 전환됩니다.
3. 메뉴 막대 항목을 클릭해 할당량, 오늘 상세와 모델별 사용량, 활동, 히트맵, 사용량 개요를 확인합니다.
4. 사용량 통계에서 일·주·월·연도와 표시 범위를 선택하고 날짜 레이블을 클릭하면 해당 기간의 Token, API 환산 비용, 예상 할당량 사용량, 모델별 내역을 확인할 수 있습니다.
5. 오른쪽 위 새로고침 버튼으로 데이터를 즉시 갱신합니다. 할당량 조회가 실패하면 다시 시도할 수 있습니다.
6. 가려진 이메일을 클릭하면 전체 주소가 잠시 표시됩니다. 패널을 닫으면 다시 가려집니다.
7. 왼쪽 아래 톱니바퀴로 설정을 열어 시작 방식, 모드, 언어, 메뉴 막대 링 크기, 카드 표시와 순서, 글꼴, 할당량 배경, 자동 새로고침 간격, 데이터 관리를 변경합니다. Codex 앱과 함께 시작·종료와 로그인 시 실행은 동시에 사용할 수 없으며 하나를 켜면 다른 하나가 꺼집니다. macOS에서 요구하면 시스템 설정의 로그인 항목에서 백그라운드 실행을 허용하세요.
8. 글꼴에서 수치, 제목, 레이블·설명의 크기를 통계 카드별 또는 일괄 조절합니다. 한도 카드는 별도로 설정합니다. 변경 사항은 즉시 적용되고 자동 저장되며 기본값 복원도 가능합니다.
9. 오른쪽 아래 전원 버튼으로 앱을 종료합니다.

## 데이터와 개인정보

- 계정 요약은 `account/read`에서 가져옵니다.
- 할당량 기간과 Credits 잔액은 `account/rateLimits/read`에서 가져옵니다. 비율은 각 기간의 사용된 부분을 나타내며 Credits는 서버가 반환한 잔액을 미화로 환산합니다.
- 오늘의 할당량 사용 비율은 로컬 Codex 로그의 할당량 기록으로 추정합니다. 현재 기본 할당량 기간에 맞춰 집계하고 재설정 경계를 넘는 차이는 제외합니다. 다른 기기 사용량이나 서버 동기화 지연에 따라 차이가 있을 수 있습니다. 비교용 시간과 비율 메타데이터만 로컬 SQLite에 저장하며 대화 내용은 저장하지 않습니다.
- Token 활동과 히트맵은 `account/usage/read`에서 가져오며 할당량 상한과는 다른 활동 통계입니다.
- 오늘의 Token과 누적 API 환산 비용은 로컬에 남아 있는 Codex 세션 및 보관 로그의 token 카운트 이벤트만 읽으며 대화 내용은 저장하거나 표시하지 않습니다. 오늘 통계는 과거 기록 스캔을 기다리지 않고 독립적으로 갱신됩니다. 누적 비용은 처음에 과거 기록을 백그라운드로 읽고, 이후 5초마다 파일 변경을 확인해 새로 추가된 로그만 계산합니다. 일별 집계, 비용, 읽기 위치는 로컬 SQLite에 저장하며 재시작 후에도 읽기 진행 상황을 재사용합니다. 집계 범위는 서버의 계정 누적 Token과 다를 수 있습니다.
- API 환산 비용은 앱에 포함된 모델별 API 요금표로 추정하며 일반 입력, 캐시 읽기·쓰기, 출력, 지원 모델의 긴 컨텍스트를 구분합니다. 인식할 수 없는 Codex 내부 라우트는 GPT-5.6 Sol 요금을 사용합니다. 과거 사용량에도 현재 내장 요금표를 적용하며 도구 비용, Fast 모드, 지역별 추가 요금은 포함하지 않습니다. ChatGPT 구독의 실제 청구액이 아닙니다.
- 사용량 통계는 일별·주별·월별·연도별을 지원합니다. 일별은 오늘을 제외하고 어제부터 이전 7 / 14 / 30일을 표시합니다. 주별은 현지 시간 월요일~일요일로 집계하며 최근 4 / 8 / 12주를 표시합니다(기본 4주). 월별은 최근 3 / 6 / 12개월, 연도별은 최근 3 / 5년 또는 전체 연도를 표시합니다. 주·월·연도 통계에는 오늘이 포함되며 이번 주는 현재까지의 집계입니다. 오늘의 모델별 사용량은 오늘 상세에 표시합니다. 각 집계 단위의 범위를 별도로 기억하며 날짜 레이블을 클릭하면 해당 기간의 Token, API 환산 비용, 할당량 사용량, 모델별 내역을 확인할 수 있습니다. 할당량 사용량은 선택한 기간의 기록값 변화로 추정하며 계산할 수 있는 기록이 없으면 “—”를 표시합니다. 기존 시간별 선택은 일별로 자동 전환되며 카드 표시, 순서, 글꼴 설정은 유지됩니다.
- 최장 작업은 현재 계정에 대해 서버가 반환한 `longestRunningTurnSec`를 사용합니다. 값은 초 단위이며 화면에는 분까지 표시합니다. 단일 작업의 최장 시간이며 전체 대화의 누적 시간이 아닙니다.
- 앱은 `auth.json`에 접근하지 않고 액세스 토큰을 저장하지 않으며 전체 서버 응답을 기록하거나 추가 데이터를 업로드하지 않습니다.
- API Key 또는 Amazon Bedrock 로그인은 ChatGPT 할당량이나 활동 데이터를 반환하지 않을 수 있습니다. 이 지표가 필요하면 ChatGPT 로그인을 사용하세요.

### 로컬 데이터와 정리

- 앱의 통계, 설정, 배경 구성, 배경 이미지는 모두 `~/Library/Application Support/CodexMeter/meter.sqlite`에 저장합니다. SQLite는 WAL과 트랜잭션을 사용하며 변경된 로그의 읽기 위치와 일별 통계만 갱신합니다. 현재 계정 할당량, 화면 스냅샷, 디코딩한 이미지는 메모리에 보관합니다.
- 첫 실행 시 기존 UserDefaults 설정, 배경 이미지, `~/Library/Caches/CodexMeter/usage-{today,history}.json`을 이전하고 데이터베이스에 성공적으로 쓴 후에만 해당 기존 데이터를 삭제합니다. Codex 자체의 세션 로그, 로그인 정보, macOS/Sparkle이 관리하는 상태는 앱 데이터베이스에 포함되지 않습니다.
- 오늘 상세와 활동 개요는 독립된 카드로 설정 → 표시에서 각각 켜고 끄거나 드래그해 순서를 바꿀 수 있습니다. 업데이트 시 기존 순서를 유지하고 새 활동 개요를 오늘 상세 뒤에 추가하며 기존 표시 상태를 이어받습니다.
- 설정 → 데이터 관리에서 데이터베이스 전체 크기(WAL 포함), 배경 이미지 크기, 저장된 통계의 날짜 범위를 확인할 수 있습니다. 7, 30, 90, 180, 365일 이전, 지정한 일수 이전 또는 기록된 모든 로컬 통계를 정리할 수 있습니다. 정리 전에 정확한 기준 시점을 표시하고 정리 후 공간을 회수합니다. 설정, 배경 이미지, Codex 원본 로그는 유지되며 계정 할당량과 서버 통계에는 영향을 주지 않습니다.
- 정리 기준 시점은 영구 저장되므로 삭제된 과거 이벤트는 재시작이나 로그 이동·재작성으로 다시 가져오지 않습니다. 새 사용량은 정상적으로 기록합니다. 중복 가져오기를 막기 위해 일부 읽기 위치를 유지하므로 통계를 모두 지워도 데이터베이스 크기는 0바이트가 되지 않습니다.
