# 日 / 月 / 年用量统计验证

> 历史记录：此文保留当时的设计或验证结果。v1.7.0 的当前界面使用每日 / 每周 / 每月 / 每年统计，按日期展示模型明细与额度估算；每日从昨天开始。最新说明与原生截图见[主 README](../../../README.md)。

2026-09-23，按已确认的 `designs/usage-statistics-panel/Usage Statistics.html` 实现。

- 「月度统计」改为「用量统计」，支持每日、每月、每年。
- 每日范围为 7 / 14 / 30 天；每月为 3 / 6 / 12 个月；每年为 3 / 5 年或全部有记录年份（包含中间空缺年份）。
- 各周期独立保存范围；在卡片内切换周期时保留所选日期。范围、当前周期跨启动保存。
- 日期按钮与柱状图同步；无记录显示「—」，明确记录为零时显示零。
- 复用本机逐日缓存及原有月份汇总；保留旧的显隐、排序、字体和月份范围设置。
- 六种界面语言均已补齐。

## 验证结果

- 全量测试：84 项 / 18 个测试组通过。
- 最后的空值显示和视图计算调整后，相关 5 项测试通过。
- 关键断言覆盖夏令时日界、跨年、闰年、未来记录排除、缺失与零值、全部年份、旧设置兼容、各周期范围恢复、扫描缓存重用以及历史清理。
- 渲染测试覆盖 3 个周期 × 3 个范围 × 6 种语言 × 深浅外观。
- 使用独立临时数据库的原生窗口验证：点击昨天，数值和柱子同步；切换到每年并选择近 5 年；选择无记录年份；切回每日恢复昨天；设置页周期与范围同步。

`statistics-*.png` 为最终代码通过 NSHostingView 导出的卡片截图（示例数据）；`native-daily.png` 和 `native-settings.png` 为原生交互验证截图。

测试使用 `CODEX_METER_DATA_DIRECTORY` 指向临时目录，避免测试访问正常使用的数据库。没有变更数据库结构。
