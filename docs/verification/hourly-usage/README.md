# 每小时用量统计验证

> 历史记录：此文保留当时的设计或验证结果。v1.7.0 的当前界面使用每日 / 每周 / 每月 / 每年统计，按日期展示模型明细与额度估算；每日从昨天开始。最新说明与原生截图见[主 README](../../../README.md)。

2026-09-23，在日 / 月 / 年统计基础上加入每小时。

- 小时范围为近 6 / 12 / 24 小时，默认 24 小时，包含当前小时；与其他周期分别记住范围。
- 按日志事件时间和本地时区汇总 Token、API 等效费用；跨日与夏令时均按实际小时划分，重复的本地小时通过时区标识区分。
- SQLite 升级到 schema 2，增加按文件存储的小时统计。旧检查点只补读一次原日志，之后继续增量扫描，重启直接恢复缓存。
- 数据清理同时覆盖小时与每日缓存，升级补读不会恢复已排除的历史事件。
- 无记录与明确零值分别显示；日期按钮与柱子联动。没有新日志时，整点仍会推进显示范围。
- 保留原有卡片显隐、排序、字体以及日 / 月 / 年设置，补齐六种语言。

## 验证

- 全量 87 项测试、18 个测试组通过。
- 调整密集柱状图的轴标注后，相关 13 项测试再次通过。
- 渲染覆盖 4 个周期 × 3 个范围 × 6 种语言 × 深浅外观。
- 重点覆盖跨午夜、夏令时跳时与重复小时、Token 与费用汇总、未来记录、空缺与零值、旧 JSON / SQLite 缓存迁移、清理后升级、重启不重复扫描、范围设置恢复及无新用量时的整点更新。
- `statistics-*.png` 是原生 NSHostingView 导出的卡片截图，使用示例数据；已检查小时模式的深浅外观。

测试通过 `CODEX_METER_DATA_DIRECTORY` 使用独立临时数据库，不修改用户实际用量数据。

发布构建通过：macOS 通用二进制包含 arm64 / x86_64，应用与内嵌框架的本地签名验证通过。安装包为 `dist/CodexMeter-1.5.1-macOS-hourly.zip`，ZIP 完整性验证通过，并提供同名 `.sha256` 文件。
