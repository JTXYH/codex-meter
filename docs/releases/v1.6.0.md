# Codex Meter 1.6.0

## What's new

- The menu bar now shows a fixed, colored quota ring that matches the dashboard ring. It tracks the remaining quota, keeps its adjustable size, and no longer offers an icon-style switch. The small ring's stroke is inset so it stays circular instead of being clipped into a rounded square.
- Added separate Activity Overview and Usage Statistics cards. Usage Statistics explores hourly, daily, monthly, and yearly local token usage and API-equivalent cost, with independent saved ranges for each period.
- Added card-specific font controls alongside shared content typography. The quota card keeps its own font settings, and previews use the same card layouts as the dashboard.
- Moved app preferences, quota backgrounds, local usage totals, and log-reading checkpoints into SQLite. Existing settings and cached usage are migrated on upgrade. Data Management shows storage usage and lets you clear recorded local statistics by age while retaining settings and background images.
- Improved local usage accounting for archived sessions, cumulative token events, rewritten logs, and model-specific API-equivalent prices. Today's usage continues to refresh independently of the historical scan.
- Replaced the README screenshots with full-height light and dark captures that show all seven dashboard cards using demo data.

## Downloads

- `CodexMeter-1.6.0-macOS.zip` — Universal 2 app for Apple Silicon and Intel Macs, macOS 14 or later.
- `CodexMeter-1.6.0-macOS.zip.sha256` — SHA-256 checksum for the app archive.
- `appcast.xml` — signed Sparkle update feed.

Users on Sparkle-enabled versions can update in the app. For a manual install, quit the existing app, unzip the download, and replace `CodexMeter.app` in Applications. The app is ad-hoc signed and has not been notarized by Apple; if macOS blocks the first launch, Control-click the app in Finder and choose **Open**.
