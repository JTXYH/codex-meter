# Codex Meter v2.0.0

Codex Meter 2.0 重新设计了主面板和设置中心，保留两种主题，并统一了账号历史与本机今日统计的日期边界。

## 本次更新

- 新增 A「轻量」紫色圆环与 B「数据」绿色刻度两种主题，共用设置中心；强调色随主题变化，均支持浅色、深色及跟随系统。
- 主面板从菜单栏弹出，头部随内容滚动。更新应用图标、加载画面、弹出与内容切换动画，减少菜单栏两侧留白。
- 今日明细按 UTC 统计本机输入、输出、缓存输入和模型 Token，每 5 秒增量刷新；历史统计、热力图和账号摘要使用官方账号接口，包含其他设备和云端任务，不混入本机实时计数。
- 历史统计支持日、周、月、年，显示模型名称、Fast 标记及可用的模型使用占比。占比来自同次官方响应的 `credits` 权重，不是 Token 占比或费用。
- 两种主题都加入充值卡模块，显示官方可用数量和逐张到期时间。卡片按到期时间排列，内部使用留白分隔；查看卡片不会执行额度重置。
- 支持自定义额度状态文字、卡片显隐和排序、菜单栏圆环大小、分卡片字号、刷新频率和启动方式。
- 保留 Credits 余额。应用按固定 `1 Credit = US$0.04` 换算显示，不代表 API 用量账单。
- 移除 API 费用计算、费用设置、背景和自定义图标功能，清理不再使用的代码与设计资料，重写六种语言 README。

## 安装与更新

下载 `CodexMeter-2.0.0-macOS.zip`，解压后将 `CodexMeter.app` 放入“应用程序”。需要 macOS 14 或更高版本，安装包同时支持 Apple Silicon 和 Intel。先在 Codex 桌面应用或 CLI 中使用 ChatGPT 账号登录。

已有支持 Sparkle 的版本可在“关于与更新”中检查更新。Release 提供 ZIP、SHA-256 校验文件和 `appcast.xml`。

本次安装包采用 ad-hoc 签名，未经 Apple 公证。首次打开可能需要在 macOS“隐私与安全性”中允许。

升级保留应用设置与本机统计。此前线上的 `master` 已保存在 `V1.0` 分支，`master` 从本次发布起维护 2.0 版本。

## 数据说明

- 今日和历史用量按 UTC 划分日期；重置与到期时间按 Mac 当前时区显示。
- 充值卡数量与明细分别来自接口字段。若接口只返回数量，应用会保留数量并提示明细不可用，不编造到期时间。
- 本机设置、计数和读取位置保存在 SQLite；应用不保存或上传会话正文。

## English

Codex Meter 2.0 introduces two panel themes and a shared settings center, with consistent UTC day boundaries for account history and today's local counters.

- Choose a purple ring or a green horizontal gauge. Settings follow the theme accent, with system, light, and dark appearance.
- Open the panel from the menu bar. The header scrolls with the content, with a new app icon, loading screen, and panel transitions.
- View local input, output, cached input, and model tokens with incremental updates every 5 seconds. Historical totals, activity summaries, and the heatmap use official account data across devices and cloud tasks.
- Browse daily, weekly, monthly, and yearly history, model names, Fast labels, and available model shares. Shares use `credits` weights within one official response, not token counts or dollar costs.
- View the official reset-card count and each card's expiry in both themes. Cards are read-only and ordered by expiry.
- Customize quota messages, card visibility and order, ring size, font sizes, refresh intervals, and startup behavior.
- Keep the Credits balance display, converted at a fixed `1 Credit = US$0.04`. API cost calculations and settings, backgrounds, and custom icons have been removed.
- Remove unused code and design files and rewrite all six README translations.

Requires macOS 14 or later. The ZIP supports Apple Silicon and Intel Macs. Sign in to Codex with a ChatGPT account before opening Codex Meter. Existing Sparkle-enabled installations can check for updates in the app.

This release uses ad-hoc signing and is not Apple-notarized. Settings and local statistics are preserved on upgrade. The previous published `master` is available on `V1.0`; `master` now tracks version 2.0.
