## Codex Meter 1.0.0

### What's new

- Added built-in update checks when the app starts and every six hours while it is running.
- Added an Update section in Settings for manual checks and current-version information.
- Added update prompts with release notes and direct actions to download the package or view the GitHub Release.
- Added a Cloudflare Worker update service that reads the latest public GitHub Release, normalizes its metadata, and caches it at the edge.

### Downloads

- `CodexMeter-1.0.0-macOS.zip`: Universal macOS app for Apple Silicon and Intel Macs.
- `CodexMeter-1.0.0-macOS.zip.sha256`: SHA-256 checksum for the app archive.

### Automatic updates

Codex Meter checks the Cloudflare update endpoint below. Release binaries remain hosted on GitHub and are downloaded directly from the corresponding GitHub Release asset.

`https://codex-meter-updates.tianxiang1314520.workers.dev/v1/releases/latest`

> The app uses an ad-hoc signature and is not notarized by Apple. If macOS blocks the first launch, right-click CodexMeter in Finder and choose **Open**.
