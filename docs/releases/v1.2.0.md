## Codex Meter 1.2.0

### What's new

- Added custom quota-background sets in Settings, with separate images for plenty remaining (70–100%), attention (30–69%), and running low (0–29%).
- Added interactive crop, zoom, pan, and rotation controls with a live weekly-card preview.
- Added optional custom panel icons for each quota state and automatic background/icon switching as the remaining quota changes.
- Added profile creation, rename, selection, deletion, enable/disable controls, and persistent local storage for background settings and processed images.
- Added signed Sparkle 2 updates that can verify, install, and relaunch the app in place. This is the transition release from the legacy browser-download updater.
- Disabled update checks and launch-at-login registration in debug builds to avoid development-only prompts and duplicate Login Items.
- Added localized background settings and update states for Simplified Chinese, Traditional Chinese, English, Japanese, Korean, and Spanish.

### Downloads

- `CodexMeter-1.2.0-macOS.zip`: Universal macOS app for Apple Silicon and Intel Macs.
- `CodexMeter-1.2.0-macOS.zip.sha256`: SHA-256 checksum for the app archive.
- `appcast.xml`: Signed Sparkle update feed.

### Upgrade note

Codex Meter 1.1.0 and earlier still open the browser to download updates. Install 1.2.0 manually once; later releases can update in-app through Sparkle.

> The app uses an ad-hoc signature and is not notarized by Apple. If macOS blocks the first launch, right-click CodexMeter in Finder and choose **Open**.
