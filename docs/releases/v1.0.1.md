## Codex Meter 1.0.1

### What's new

- Added native launch-at-login support, enabled by default and configurable from General Settings.
- Improved first-run preferences: Codex Meter follows the macOS appearance and selects the primary system language, falling back to English when that language is unsupported.
- Refined typography throughout the usage panel with a lighter, clearer visual hierarchy.

### Downloads

- `CodexMeter-1.0.1-macOS.zip`: Universal macOS app for Apple Silicon and Intel Macs.
- `CodexMeter-1.0.1-macOS.zip.sha256`: SHA-256 checksum for the app archive.

### Automatic updates

Codex Meter checks the Cloudflare update endpoint below. Release binaries remain hosted on GitHub and are downloaded directly from the corresponding GitHub Release asset.

`https://codex-meter-updates.tianxiang1314520.workers.dev/v1/releases/latest`

> The app uses an ad-hoc signature and is not notarized by Apple. If macOS blocks the first launch, right-click CodexMeter in Finder and choose **Open**.
