# Codex Meter 1.7.0

## What's new

- **Per-model usage details.** Today's Details and Usage Statistics now show each model's input tokens, output tokens, API-equivalent cost, and share of local token usage. Historical model records are restored from existing session logs on upgrade, while previously cleared data stays excluded.
- **Estimated quota usage.** See observed quota consumption alongside tokens and cost, both for today and for a selected day, week, month, or year. Estimates use local quota observations for the current primary quota window and account for resets. They can exceed 100% when several windows are combined; missing observations show `—`. Other devices and server synchronization can affect the estimate.
- **Weekly statistics and clearer date ranges.** Explore daily, weekly, monthly, and yearly usage. Weeks run Monday–Sunday in your local time zone, with 4-, 8-, or 12-week ranges. Daily statistics start yesterday, keeping today's model details in their own card. Existing hourly selections move to daily; saved card visibility, order, fonts, and other ranges are retained.
- **Follow the Codex desktop app.** Enable an optional background watcher to open Codex Meter when Codex launches and close it when Codex quits. This mode and Launch at Login are mutually exclusive, and failed mode switches restore the previous setting when possible. macOS may require background-item approval.
- **Improved CLI discovery.** Automatic discovery prioritizes the CLI bundled with the ChatGPT/Codex desktop apps. An explicitly configured CLI path still takes precedence.
- **Local usage stays available after a quota request fails.** Even if the first account request fails, local usage cards continue to load and the quota card offers Retry. Later failures retain the last successful account snapshot.
- **Updated documentation and screenshots.** All six README languages now describe the current statistics, startup modes, font controls, and local data management. Native light and dark captures use synthetic demo data.

## Downloads and installation

- `CodexMeter-1.7.0-macOS.zip` — Universal 2 app for Apple Silicon and Intel Macs, macOS 14 or later.
- `CodexMeter-1.7.0-macOS.zip.sha256` — SHA-256 checksum for the archive.
- `appcast.xml` — signed Sparkle update feed.

Users on Sparkle-enabled versions can update in the app. For a manual install, quit the existing app, unzip the download, and replace `CodexMeter.app` in Applications. The app is ad-hoc signed and has not been notarized by Apple; if macOS blocks the first launch, follow the instructions in the [README](https://github.com/JTXYH/codex-meter/blob/v1.7.0/README.en.md#if-macos-blocks-the-app-on-first-launch).

Per-model totals and quota observations are stored in the existing local SQLite database. API-equivalent costs are estimates based on the app's bundled rates, not actual ChatGPT subscription charges. See the [data and privacy documentation](https://github.com/JTXYH/codex-meter/blob/v1.7.0/README.en.md#data-and-privacy) for scope and cleanup behavior.
