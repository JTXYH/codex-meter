## Codex Meter 1.5.0

### What's new

- Extended the activity heatmap from 90 to 120 days while restoring the compact 14-point square size.
- Filled the full heatmap width with 18 weekday-aligned columns and adaptive column spacing.
- Added neutral boundary squares for dates outside the 120-day range, removing the apparent empty block at the beginning and end of the calendar.
- Updated heatmap totals, labels, settings descriptions, demo data, and all six interface localizations for the new 120-day range.
- Refined the Credits balance card icon for a cleaner match with the dashboard visual system.
- Refreshed the light and dark README screenshots and expanded every localized README to describe the current dashboard, Credits, customization, refresh, appearance, and startup features.
- Added regression coverage for the 120-day, 18-column heatmap layout.

### Downloads

- `CodexMeter-1.5.0-macOS.zip`: Universal macOS app for Apple Silicon and Intel Macs.
- `CodexMeter-1.5.0-macOS.zip.sha256`: SHA-256 checksum for the app archive.
- `appcast.xml`: Signed Sparkle update feed.

### Upgrade note

Codex Meter 1.2.0 and later can install this release in-app through Sparkle. Users running 1.1.0 or earlier still use the browser-download updater and need to install 1.5.0 manually once.

> The app uses an ad-hoc signature and is not notarized by Apple. If macOS blocks the first launch, right-click CodexMeter in Finder and choose **Open**.
