# Codex Meter

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · 日本語 · [한국어](README.ko.md) · [Español](README.es.md)

Codex Meter は、ChatGPT/Codex アカウントの割り当てウィンドウと token アクティビティをすばやく確認できるネイティブ macOS メニューバーユーティリティです。ローカルの Codex CLI `app-server` JSON-RPC インターフェースからデータを読み取り、既存のログイン状態を再利用します。アクセストークンは読み取りも保存もしません。

> Codex Meter は独立したオープンソースプロジェクトです。OpenAI の公式製品ではなく、OpenAI によるサポートまたは推奨を意味しません。

## 主な機能

- メニューバーに Codex の 5 時間残量を優先表示し、アカウントが週間割り当てのみを返す場合は自動で週間残量に切り替え
- 割り当てカードと同じ色の進捗リングをメニューバーに表示し、残量に合わせて更新。サイズは 12〜22 pt で調整でき、即時プレビューに対応
- API が返すウィンドウに合わせて割り当てカードを自動調整。5 時間割り当てはリセットまでの時間と時刻、週間割り当ては残量とリセット日を 1 行で表示
- 今日の内訳、昨日、過去 7 日間、今月、累計の Token と API 換算料金、連続使用日数、最長タスクを表示
- 曜日ごとに整列したコンパクトなマスで過去 120 日間のヒートマップを表示し、ポインターを置くと日ごとの使用量を確認可能
- 今日の Token をローカル Codex セッションログから 5 秒ごとに差分更新し、入力、出力、キャッシュ入力、米ドルの API 換算料金を表示
- 今日の内訳に割り当て消費の推定割合を表示。使用量の統計では Token、API 換算料金、選択した期間の割り当て消費を並べて表示
- 今日の内訳にモデルごとの入力・出力 Token、API 換算料金、使用割合を表示。使用量の統計でも同じ形式で、選択した日・週・月・年のモデル別内訳を表示
- Codex Credits 残高を米ドルに換算して表示
- メインパネルの全カードを個別に表示・非表示、ドラッグで並べ替えでき、設定は自動保存
- 手動更新、プリセットの更新間隔、1〜1,440 分のカスタム間隔に対応
- ログイン時の自動起動、または Codex デスクトップアプリと連動した起動・終了に対応。外観はシステム、ライト、ダークから選択
- 割り当て取得には Codex/ChatGPT デスクトップアプリ内蔵の CLI を優先し、手動指定した CLI パスがある場合はそれを最優先
- 数値、見出し、ラベル・説明の文字サイズを内容カードごと、または一括で調整。割り当てカードは独立して設定可能
- 複数のカスタム割り当て背景セットを作成し、「十分・注意・わずか」の各状態でカード画像とパネルアイコンを切り抜いて、残量に応じて自動切り替え
- Sparkle で 6 時間ごとに更新を確認し、アプリ内で検証、インストール、再起動
- アカウントのメールアドレスを初期状態でマスクし、クリックしたときだけ全体を表示
- 割り当て更新に失敗しても前回の成功データを保持。初回の取得に失敗してもローカル使用量を表示し、割り当ての再試行が可能
- 統計、設定、背景画像をローカル SQLite に保存し、設定から期間を指定して使用履歴を削除可能

### 初回起動時に macOS にブロックされる場合

現在のビルドは ad-hoc 署名で、Apple のノータリゼーションは未実施です。初回起動時に「アプリにマルウェアが含まれていないことを Apple では確認できません」または「開発元を検証できません」と表示された場合は、まず本リポジトリの [GitHub Releases](https://github.com/JTXYH/codex-meter/releases) からダウンロードしたアプリであることを確認し、以下のいずれかの方法を使用してください。

**方法 1：Finder から開く**

1. Finder で「アプリケーション」を開き、`CodexMeter.app` を探します。
2. Control キーを押しながらアプリをクリックするか、右クリックして、「開く」を選びます。
3. 確認ダイアログでもう一度「開く」をクリックします。一度許可すれば、次回からはダブルクリックで通常どおり起動できます。

**方法 2：システム設定から許可する**

1. `CodexMeter.app` を一度ダブルクリックし、macOS の警告を閉じます。
2. Apple メニュー ** → システム設定 → プライバシーとセキュリティ** を開きます。
3. 「セキュリティ」まで下にスクロールし、Codex Meter のメッセージにある「このまま開く」をクリックします。
4. 求められた認証を完了し、「開く」をクリックします。「このまま開く」ボタンは、通常、アプリを開こうとした後の約 1 時間だけ表示されます。

詳細は [Apple サポート：Mac でアプリを安全に開く](https://support.apple.com/ja-jp/102445) を参照してください。macOS にアプリが「コンピュータを破損します」と明示された場合や、マルウェアが検出された場合は、警告を無視しないでください。現在のファイルを削除し、公式 Release から再度ダウンロードしてください。

Sparkle を内蔵した最初のバージョン以降、更新パッケージは Ed25519 で署名され、アプリ内でインストールされます。旧バージョンがブラウザ経由のダウンロードを使用している場合は、一度だけ移行用バージョンを手動インストールしてください。その後の更新では同じ Gatekeeper の確認を繰り返す必要はありません。

## 動作要件

- macOS 14 Sonoma 以降
- Codex/ChatGPT デスクトップアプリ内蔵、または単独でインストールした [Codex CLI](https://github.com/openai/codex) が利用可能で、ChatGPT アカウントにログイン済みであること
- Swift 6 / Xcode 16 以降（ソースからビルドする場合のみ）

Codex Meter は手動指定した CLI パスを最優先し、その後 Codex/ChatGPT デスクトップアプリ内蔵の `codex`、`PATH`、`~/.local/bin/codex`、`~/.npm-global/bin/codex`、Homebrew の一般的な場所、その他のアプリ内の実行ファイルを探します。

## インストール

リポジトリをクローンまたはダウンロードした後、次を実行します。

```bash
cd codex-meter
chmod +x scripts/build-app.sh
./scripts/build-app.sh
```

`dist/CodexMeter.app` が作成されます。直接開くか、「アプリケーション」フォルダに移動してください。

開発中は次のコマンドで直接実行できます。

```bash
swift run CodexMeter
```

## 使い方

1. Codex CLI または Codex デスクトップアプリで、ChatGPT アカウントにログイン済みであることを確認します。
2. Codex Meter を起動すると、メニューバーに色付きの割り当てリングと 5 時間残量が表示されます。週間割り当てのみの場合は自動で週間残量に切り替わります。
3. メニューバー項目をクリックして、割り当て、今日の内訳とモデル別使用量、アクティビティ、ヒートマップ、使用状況を確認します。
4. 「使用量の統計」で日・週・月・年と表示範囲を選び、日付ラベルをクリックすると、その期間の Token、API 換算料金、割り当て消費の推定値、モデル別内訳が表示されます。
5. 右上の更新ボタンで、データをすぐに更新できます。割り当ての取得に失敗した場合は再試行できます。
6. マスクされたメールアドレスをクリックすると、全体を一時的に表示します。パネルを閉じると再び隠れます。
7. 左下の歯車から設定を開き、起動方法、外観、言語、メニューバーリングのサイズ、カードの表示・順序、文字サイズ、割り当て背景、自動更新間隔、データ管理を変更します。「Codex と連動して起動・終了」と「ログイン時に起動」は併用できず、一方をオンにすると他方がオフになります。macOS から求められた場合は、システム設定のログイン項目でバックグラウンド実行を許可してください。
8. 「文字」では数値、見出し、ラベル・説明のサイズを、統計カードごと、または一括で調整できます。「上限カード」は独立して設定します。変更は即時反映・自動保存され、初期値にも戻せます。
9. 右下の電源ボタンでアプリを終了します。

## データとプライバシー

- アカウント概要は `account/read` から取得します。
- 割り当てウィンドウと Credits 残高は `account/rateLimits/read` から取得します。割合は各ウィンドウの使用済み部分を表し、Credits はサーバーが返した残高を米ドルに換算します。
- 今日の割り当て消費は、ローカル Codex ログに含まれる割り当て記録から推定します。現在の主ウィンドウに合わせて集計し、リセット境界をまたぐ差分は避けます。他のデバイスでの使用やサーバーの同期遅延によって差が出る場合があります。比較に使う時刻と割合のメタデータのみをローカル SQLite に保存し、会話内容は保存しません。
- Token アクティビティとヒートマップは `account/usage/read` から取得し、割り当て上限とは異なる統計です。
- 今日の Token と累計 API 換算料金は、ローカルに存在する Codex セッション・アーカイブログの token カウントイベントのみを読み取り、会話内容は保存・表示しません。今日の統計は履歴スキャンを待たずに独立して更新します。累計料金は初回に履歴をバックグラウンドで読み取り、その後は 5 秒ごとにファイルの変更を確認して追加分のみを計算します。日別集計、料金、読み取り位置はローカル SQLite に保存し、再起動後も読み取りの進捗を再利用します。対象範囲はサーバーのアカウント累計 Token と異なる場合があります。
- API 換算料金はアプリ内蔵のモデル別 API 料金表で推定し、通常入力、キャッシュ読み取り・書き込み、出力、対応モデルの長いコンテキストを区別します。識別できない Codex 内部ルートには GPT-5.6 Sol の料金を適用します。履歴にも現在の内蔵料金表を使い、ツール料金、Fast モード、地域による追加料金は含みません。ChatGPT サブスクリプションの実際の請求額ではありません。
- 使用量の統計は日別・週別・月別・年別に対応します。日別は今日を含まず、昨日から過去 7 / 14 / 30 日を表示します。週別は現地時間の月曜〜日曜で集計し、直近 4 / 8 / 12 週を表示します（初期値は 4 週）。月別は直近 3 / 6 / 12 か月、年別は直近 3 / 5 年またはすべての年を表示します。週・月・年は今日を含み、今週は現在時点までの集計です。今日のモデル別使用量は「今日の内訳」に表示します。各集計単位で範囲を個別に記憶し、日付ラベルをクリックすると、その期間の Token、API 換算料金、割り当て消費、モデル別内訳を確認できます。割り当て消費は選択した期間の記録値の変化から推定し、計算できる記録がなければ「—」を表示します。以前の「時間別」の選択は「日別」に自動移行し、カードの表示・順序・文字設定は保持します。
- 最長タスクは現在のアカウントについてサーバーが返す `longestRunningTurnSec` を使用します。値は秒単位で、画面では分まで表示します。単一タスクの最長時間であり、会話全体の合計時間ではありません。
- アプリは `auth.json` にアクセスせず、アクセストークンの保存、サーバー応答全体の記録、追加データのアップロードも行いません。
- API Key または Amazon Bedrock ログインでは ChatGPT の割り当てやアクティビティが返らない場合があります。これらの指標が必要な場合は ChatGPT ログインを使用してください。

### ローカルデータと削除

- アプリの統計、設定、背景構成、背景画像はすべて `~/Library/Application Support/CodexMeter/meter.sqlite` に保存します。SQLite は WAL とトランザクションを使用し、変更されたログの読み取り位置と日別統計のみを更新します。現在のアカウント割り当て、画面のスナップショット、デコードした画像はメモリに保持します。
- 初回起動時に従来の UserDefaults 設定、背景画像、`~/Library/Caches/CodexMeter/usage-{today,history}.json` を移行し、データベースへの書き込み成功後に対応する旧データを削除します。Codex 自体のセッションログ、ログイン情報、macOS/Sparkle が管理する状態は、このデータベースには含まれません。
- 「今日の内訳」と「アクティビティ概要」は独立したカードです。「設定 → 表示」で個別に表示・非表示や並べ替えができます。更新時は既存の順序を保持し、新しいアクティビティ概要は今日の内訳の後に追加され、従来の表示状態を引き継ぎます。
- 「設定 → データ管理」でデータベースの合計容量（WAL を含む）、背景画像の容量、保存済み統計の日付範囲を確認できます。7、30、90、180、365 日より前、指定した日数より前、または記録済みのローカル統計すべてを削除できます。削除前に具体的な期限を表示し、削除後に空き容量を回収します。設定、背景画像、Codex の元ログは保持され、アカウントの割り当てやサーバー統計には影響しません。
- 削除の期限は永続保存され、削除済みの古いイベントは再起動、ログの移動、書き換えでも再取り込みされません。新しい使用量は通常どおり記録します。再取り込みを防ぐため少量の読み取り位置を保持するので、統計をすべて削除してもデータベースは 0 バイトにはなりません。
