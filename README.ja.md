## 機能

- **2 つのテーマ**：紫の円形ゲージを使うシンプルパネルと、緑の横型ゲージを使うデータパネル。設定画面のアクセントカラーもテーマに合わせて変わります。システム連動、ライト、ダークの外観に対応しています。
- **残り枠とリセット時刻**：メニューバーでは 5 時間枠を優先し、週間枠しかない場合はそちらを表示します。パネルにはアカウントから返された枠とリセット時刻を表示します。利用可能、残量わずか、リセット待ちのメッセージは変更できます。
- **今日の詳細**：本機の Token カウンターを 5 秒ごとに差分読み込みし、入力、出力、キャッシュ入力、モデル別の内訳を表示します。
- **アカウント履歴**：公式アカウント API の日・週・月・年別 Token 合計。ほかのデバイスとクラウドタスクも含みます。モデル名、Fast 表示、取得できたデータに基づく使用比率も確認できます。
- **アクティビティ**：昨日、直近 7 日、今月の使用量、120 日間のヒートマップ、アカウントから取得した累計 Token、連続利用日数、最長の単一タスク。
- **リセットカード**：公式 API の利用可能枚数と、各カードの有効期限を期限順に表示します。閲覧専用で、カードの使用や利用枠のリセットは行いません。
- **Credits 残高**：追加利用分の残高を表示します。換算方法は下表を参照してください。
- **共通設定**：カードの表示切り替えとドラッグによる並べ替え、メニューバーのリングサイズ、全体またはカードごとの文字サイズ、更新間隔、起動方法、言語、本機データの削除。
- **更新とプライバシー**：Sparkle によるアプリ内更新。メールアドレスは通常非表示で、クリックすると一時的に表示され、パネルを閉じると再び隠れます。

簡体字中国語、繁体字中国語、英語、日本語、韓国語、スペイン語に対応しています。初回起動時はシステムの優先言語に合わせ、該当する言語がない場合は英語を使用します。

## インストールと使い方

macOS 14 Sonoma 以降が必要です。Universal ビルドは Apple Silicon と Intel Mac に対応します。先に [Codex デスクトップアプリまたは CLI](https://github.com/openai/codex) をインストールし、ChatGPT アカウントでログインしてください。

1. [GitHub Releases](https://github.com/JTXYH/codex-meter/releases/latest) から ZIP をダウンロードして展開し、`CodexMeter.app` を「アプリケーション」に移動します。
2. Codex Meter を起動し、メニューバーのリングをクリックします。
3. 右上のボタンで更新、左下の歯車で設定、右下の電源ボタンで終了します。
4. 設定で手動起動、ログイン時に起動、Codex に連動する起動を選べます。後ろの 2 つは同時には使えません。Codex 連動にはパッケージ化されたアプリが必要で、macOS の「ログイン項目と機能拡張」でバックグラウンドヘルパーの許可が必要な場合があります。

ビルドスクリプトは標準で ad-hoc 署名を使います。Apple の公証済みであることを意味しません。初回起動がブロックされた場合は、配布元と Release の SHA-256 チェックサムを確認してから、「システム設定 → プライバシーとセキュリティ」の「このまま開く」を使用してください。

リリース版は「情報と更新」で更新を確認でき、6 時間ごとの自動確認にも対応します。Sparkle が更新パッケージを検証してからインストールします。開発ビルドでは自動確認を行いません。

## データの出所と集計方法

| データ | 出所と意味 |
| --- | --- |
| アカウント、利用枠、リセット時刻 | 本機 Codex CLI の公式 `app-server`：`account/read`、`account/rateLimits/read`。 |
| Token 履歴、ヒートマップ、アカウント概要 | `account/usage/read` のアカウント統計。取得できない日付をローカル履歴で補完しません。 |
| 過去のモデルと比率 | 公式アカウントの `daily-token-usage-breakdown`。同じ応答内で各モデルの `credits` の重みを合計し、全体の重みで割った比率です。Token 比率やドル料金ではありません。重みが不完全な場合はモデル名のみ表示します。 |
| 今日の Token とモデル詳細 | 本機 Codex のセッション・アーカイブログにある当日のカウンターイベント。この Mac のみが対象です。 |
| リセットカード | `account/rateLimits/read` の `rateLimitResetCredits`。枚数は `availableCount`、期限は利用可能カードの明細を使用します。明細がない場合も公式の枚数を維持し、状態を案内します。 |
| Credits 残高 | 公式の Credits 残高を、固定の `1 Credit = US$0.04` で換算して表示します。Token に基づく API 料金とは別です。 |

今日と履歴は **UTC の日付境界**を共有し、本機の「今日」とアカウントの「昨日」が重複するのを防ぎます。週は UTC の月曜から日曜までです。枠のリセット時刻とカードの期限は Mac の現在のタイムゾーンで表示します。履歴の今日分も API 応答だけを使用し、本機のリアルタイム数値は加算しません。

API 料金の計算と関連設定は削除しました。API キーや Amazon Bedrock でのログインでは、ChatGPT アカウントの枠、モデル履歴、リセットカードを取得できない場合があります。API の反映遅延や項目不足もあり得ます。更新に失敗した場合は直前の成功データを保持し、初回失敗時は再試行を案内します。

## ローカル保存とプライバシー

設定、本機のカウンター、ログの読み取り位置は次の場所に保存します。

```text
~/Library/Application Support/CodexMeter/meter.sqlite
```

SQLite は WAL とトランザクションを使用します。アカウントの枠、履歴、モデル結果はメモリ内にのみ保持します。ログから抽出するのは使用量カウンターで、会話本文の保存やアップロードは行いません。

モデル履歴の取得には `$CODEX_HOME/auth.json`（既定値は `~/.codex/auth.json`）の既存 ChatGPT ログイン情報を使用し、アカウントを照合してから `chatgpt.com` にリクエストします。アクセストークンをアプリのデータベースやログに書き込むことはありません。

設定の本機データ画面から、保存期間を指定して統計を削除するか、すべて消去できます。元の Codex ログ、アカウント統計、設定は残ります。削除の境界を保存するため、再起動後に古いイベントが再取り込みされません。

公開 Issue にアクセストークン、`auth.json`、完全なメールアドレス、加工前のアカウント応答を添付しないでください。

## ソースからビルド

Swift 6 ツールチェーン（Xcode 16 以降）が必要です。

```bash
git clone https://github.com/JTXYH/codex-meter.git
cd codex-meter
./scripts/build-app.sh release
```

出力先は `dist/CodexMeter.app` です。ビルドのたびにプロジェクトの `dist/` 内の古い成果物を削除します。手動指定の CLI を優先し、自動検出では Codex/ChatGPT デスクトップアプリ内蔵の CLI、一般的なインストール先の順に探します。

```bash
swift run CodexMeter
swift test
```

パッケージ化と署名は[リリースガイド](docs/releasing.md)を参照してください。`master` は 2.0 のコードです。更新前に公開されていた `master` は [V1.0 ブランチ](https://github.com/JTXYH/codex-meter/tree/V1.0)に保存しています。
